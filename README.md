# ESP32-S3-MAGSAFE-HUB
I'm using an ESP32-S3-WROOM-1 N16R8 with MAGSAFE to create a bug to control varius things around the house, or just a basic desk accessory, this project will have 1 speaker with an adapter from my custom pcb encasing to hold the amplifier and the speakers using QWIIC Interface for the audio amplifier!
